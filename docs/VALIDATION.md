# 검증 기록

검증일: 2026-10-14 · Node.js 24 · Chromium · 클라우드 현재 인스턴스.

## 범위

- 단위 테스트: 도시 34개, 6개 대륙, 문항 20개, 영역 평균, 미응답 거부, 동일 입력, 대륙 필터, 연봉 영향 제한, 가치관별 순위 차이, 15,625개 선호 조합의 추천 편중
- 화면 테스트: PC 1440px, 태블릿 768px, 모바일 390px
- 시작, 기본 정보, 20문항 완료, 이전·수정, 대륙 조건, 결과, 동일 결과, PNG 다운로드, 재검사, 교사용 가상 통계
- TypeScript 및 프로덕션 빌드
- 외부 이미지 실패 시 3개 대체 표시와 기능 유지

## 진단 및 수정

- npm 기본 캐시가 쓰기 허용 경로 밖에 있어 설치 실패 → `/workspace/.npm-cache` 사용
- 초기 가중치로 동일 도시 편중 및 가치관 차이 테스트 실패 → 높은 중요도를 세제곱으로 강조하는 설명 가능한 공식으로 수정
- 모바일에서 교사용 텍스트가 숨겨져 버튼 이름이 없어짐 → 명시적 접근성 이름 추가
- Vitest가 Playwright 파일까지 실행함 → `vitest.config.ts`에서 단위 테스트 경로만 지정
- 모바일 소개 영역의 좁은 텍스트 줄바꿈 → 세로 레이아웃으로 수정
- 차트는 결과 시점에만 불러오도록 분리, 한글 폰트는 앱 내부에 포함

## 한계

- 외부 이미지 URL은 현재 네트워크 정책에서 차단되어 정상 로딩 미검증. E2E는 의도적인 이미지 실패 처리만 검증
- 이미지 3장은 공통 분위기 참고 사진이며 도시별 실제 대표 사진 아님
- 검증된 외부 도시 통계는 사용하지 않음. 비용·도시 점수는 2026 교육용 가상 시나리오
- 실제 기기 네이티브 공유 UI, Safari·Firefox·실기기, Vercel 배포, 새 클라우드 작업의 복원은 검증하지 않음
- 가상 추천 분포는 실제 학생 응답 분포나 모델 공정성을 보장하지 않음

## 최종 결과

- 잠금파일 기반 `npm ci` 재설치 성공
- 알고리즘·데이터 단위 테스트 10개 통과
- Chromium PC·태블릿·모바일 E2E 6개 통과
- TypeScript 검사 및 프로덕션 빌드 성공
- PNG 파일 시그니처와 1200×800 크기 검증
- 공유 API에 결과 문구가 전달되는 흐름은 모의 API로 검증. 실제 기기 공유창은 미검증
- 설치 스크립트, 시작 안내, `images.unsplash.com` 네트워크 요구를 환경 초안에 저장. 게시와 새 작업 복원은 미실행
